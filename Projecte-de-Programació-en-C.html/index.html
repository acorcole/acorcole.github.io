Introducció a la programació en C

Aprenentatge dels fonaments de la programació mitjançant el llenguatge C i la resolució de problemes pràctics.

1. Introducció

La programació és el procés de crear instruccions que permeten a un ordinador executar diferents tasques. En aquest projecte treballarem amb el llenguatge C, un llenguatge de programació que permet desenvolupar programes, fer càlculs i resoldre problemes matemàtics i tecnològics.

Al llarg d'aquest treball aprendrem a escriure codi, introduir dades, utilitzar variables, realitzar operacions i controlar el funcionament dels programes. També veurem que la programació va molt més enllà de fer operacions: podem crear condicions, detectar errors, reutilitzar instruccions i desenvolupar funcions pròpies.

2. Continguts treballats

01. Conceptes bàsics

Introducció a l'estructura d'un programa en C, declaració de variables, tipus de dades, operacions matemàtiques i instruccions printf i scanf.

02. Condicionals

Utilització de les estructures if, else i else if per prendre decisions segons les dades introduïdes o les condicions del programa.

03. Validació i gestió d'errors

Comprovació de les dades introduïdes per l'usuari, detecció de valors incorrectes i utilització de bucles per evitar errors.

04. Funcions pròpies

Creació de funcions pròpies per organitzar el codi, reutilitzar instruccions i dividir els programes en diferents parts.

3. Primer exemple en C

Aquest és un exemple senzill d'un programa escrit en C que mostra un missatge per pantalla. 

#include <stdio.h>

int main()
{
    printf("Hola, mon! Estic aprenent C.");

    return 0;
}

4. Objectiu del projecte

L'objectiu és aprendre a programar des de zero, comprendre com funciona el llenguatge C i aplicar els coneixements adquirits a exercicis pràctics relacionats amb la tecnologia i les matemàtiques.

Cada exercici permetrà introduir nous conceptes i millorar progressivament la manera d'escriure, estructurar i executar programes.
