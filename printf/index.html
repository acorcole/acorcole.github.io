Exercici de Tecnologia: Programació en C

Descripció

El següent codi correspon a un exercici de l'assignatura de Tecnologia, realitzat utilitzant el llenguatge de programació C.

L'exercici consisteix a crear un programa que permeti fer diferents càlculs relacionats amb l'escalfament d'aigua mitjançant un cremador de propà.

Per desenvolupar el programa s'han utilitzat variables, operacions matemàtiques, instruccions com printf() i scanf(), i diferents funcions per organitzar el codi i fer els càlculs.

Objectiu

Aprendre a utilitzar el llenguatge C, introduir i mostrar dades per pantalla, fer operacions matemàtiques i organitzar un programa mitjançant funcions.
